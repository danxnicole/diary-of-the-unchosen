# Diary of the Unchosen

A cinematic, scroll-driven 3D editorial experience for the personal writing brand **Diary of the Unchosen**.

## Stack

- React + Vite
- Three.js / React Three Fiber / Drei
- GSAP ScrollTrigger
- Lenis smooth scrolling

## Develop

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Experience

Scroll to move through an eight-stage sequence: upright cover → three-quarter turn → opening → flat reveal → page turns → close → back-cover hold. The animation is fully reversible.
