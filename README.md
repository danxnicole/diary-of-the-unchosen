# Archer

A minimalist 10-second cinematic animation of an archer releasing an arrow into a bullseye.

Built with procedural Three.js geometry and a GSAP timeline. Opens with autoplay; use **Replay** to watch again.

## Run locally

Serve the folder over HTTP (ES modules require a server):

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Open `http://127.0.0.1:8000`.
